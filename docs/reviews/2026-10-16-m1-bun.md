# M1 — Bun migration verification

Base: `main` at `fabf904` (M0). Scope: PRD-sre-lab requirement B only.

## Implementation

- B1: Bun 1.3.14, root `package.json` workspaces, one `bun.lock`; both pnpm configuration files removed.
- B2: Every root command builds shared first. Checks select all three workspaces; build selects backend/frontend after shared; each dev command selects only its service after shared.
- B3: Each Docker install uses the frozen lockfile and explicit service + shared filters. Chromium is installed by Node using the existing exact-pinned `playwright-core@1.60.0` CLI. An initial npm package-exec attempt could not find the binary in the filtered workspace; using the installed CLI avoids fetching a second tool.
- B4: Both images remain based on `node:20-slim`. A `NODE_OPTIONS` preload asserted Node 20 and recorded tsc, ESLint, Vitest, Vite and npm invocations in a clean container. No Bun runtime opt-in is used.
- B5: Generated-directory installation uses `npm install --ignore-scripts`; local tools run through `npm exec --offline --no -- <absolute-local-bin>`. A missing local binary fails before npm runs. Existing 120/60/300-second timeouts, cwd and AbortSignal remain. A separate POSIX process group cleans up npm descendants on exit/error.
- B6: Operator commands updated in AGENTS.md, both READMEs, `.agents/self-test.md`, other active operator docs and helper scripts. The generated ZIP template, README generator, version pins and CI contract test remain unchanged. The packager change is a source comment only.
